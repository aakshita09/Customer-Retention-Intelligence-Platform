# Customer Lifecycle & Retention Intelligence Platform

An end-to-end customer analytics project that analyzes e-commerce behavior to identify customer segments, purchase funnel drop-offs, and churn risk.

## Key Features
- Customer segmentation based on purchasing behavior
- Purchase funnel and cohort analysis
- Churn prediction using machine learning
- Customer-level behavioral feature engineering
- Product recommendations and retention strategies

## Project Goal
Turn customer behavior into actionable insights for improving retention, repeat purchases, and customer experience.
